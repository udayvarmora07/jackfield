## NEW vs KNOWN summary
KNOWN (already in doc 59): description quality, listing budget, overlap, evals, install security, sprawl, staleness on model upgrade, transcript to skill, rug-pull updates.
NEW or sharper: doc-vs-code drift; delete-and-measure ablation; fold subagent into skill with eval; bounded-diff and tie-rejecting validation gate for AI edits; cross-harness port with measured lift; popularity metrics are gameable (show provenance, not install counts); skill cards; version pinning and a single source repo; per-skill auto vs explicit invocation; skills compiled into scripts; guided skills for non-developers; project-scan setup recommender; viral launch anatomy.

## Feature ideas implied
1. Drift check: compare AGENTS.md/CLAUDE.md/SKILL.md claims (paths, commands, conventions) with the repo; list contradictions; offer the one-line "follow code, report discrepancies" guard.
2. Ablation tool: temporarily remove one rule or section, rerun saved cases, report "no change" so it can be deleted (ties go to deletion).
3. Subagent-to-skill converter with with/without eval before commit.
4. AI Edit guard rails: cap hunks per proposal (about 4-8), require held-out win, reject ties, show token delta, warn when a skill grows past about 1k tokens.
5. Cross-harness port that re-runs the skill's eval on the target tool and reports lift.
6. Provenance panel instead of install counts: source, author, last change since install, bundled scripts, env/network access, and a pre-enable SKILL.md preview.
7. Pin and lock skills by version/commit; "home repo" mode (one source dir, links into agent scopes); optional machine-to-machine sync.
8. Setup recommender: scan a repo and suggest which skills/agents/MCP to enable (and which installed ones are irrelevant here); presets per project type.
9. "Promote to script": detect deterministic steps in a skill and offer to extract them to scripts with checks.
10. Per-skill invocation mode toggle (auto-discover vs slash-only) surfaced in lists.
11. Bundle-aware install: curated starter packs that can be removed as one unit, to counter hype-bundle sprawl.
12. Guided skill creation for non-developers (interview, templates by job, no jargon).
13. Mine past sessions for repeated corrections and propose CLAUDE.md/skill lines (privacy-gated).
14. Before/after evidence capture for visual skills (screenshots of with vs without) to answer "slop" skepticism.
15. Skill ranking by token cost across every loaded layer (steipete's worst-offenders finder as a built-in view) and an "instruction debt audit" report across global, project, skills, agents and hooks.
