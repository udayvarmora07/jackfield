# Keycap

A small mono label for a keyboard key (`sm-kbd`), and its sibling, the agent tile (`sm-ag`), which shows each place's mark.

Keycaps teach shortcuts in place: the search box ("/"), the primary button ("Space"), and the hint line under the table. Agent tiles (`<span class="sm-ag" data-a="CX" aria-hidden="true">CX</span>`) show each place's mark (see Iconography); they identify agents in column headers and the side panel; they are decorative (`aria-hidden`) because the agent's name always sits beside them.
