# Navigation

The four global places — Skills, Needs attention, Trash & backups, Advanced — as a top bar on desktop and a bottom tab bar on phones.

Desktop (`sm-nav`): logo, the four links (current page underlined in `ink`, `aria-current="page"`), the attention count in `warn`, then the one search box ("/") and icon buttons for theme and help. Phone (`sm-tabs`): the same four places as 44px+ tabs with stroke icons and labels; search and New skill move to header icon buttons. Never add a fifth top-level place; new tools go under Advanced.
