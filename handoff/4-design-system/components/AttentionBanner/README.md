# AttentionBanner

The one place that says how many skills need attention and why, shown above the table only when the count is above zero.

Title in `title-banner` and `warn`, led by an 18px warning-triangle icon, ("3 skills need your attention"); one detail sentence that names agents and skills; two actions: "Show only these" (a toggle, `aria-pressed`) and "Fix one by one" (dark button, opens Needs attention). Never more than one banner on a page, and never a second warning colour elsewhere for the same problems.
