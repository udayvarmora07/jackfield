# UndoBar

The calm confirmation after every change to a skill's files, with Undo right there.

One inverted bar (`toast` / `on-toast`, `shadow-toast`) at the bottom centre: past-tense sentence naming the skill and agent ("Turned off code-review in Codex."), an Undo button and a dismiss ×. `role="status"`. It stays on the page where the change happened and never follows the user to another page; a newer change replaces it. If a change can't be undone, say so before acting, not here.
