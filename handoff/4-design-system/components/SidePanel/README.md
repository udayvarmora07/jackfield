# SidePanel

The answer to the selected square: what is true, what will change, and the one action, before anything happens.

Order is fixed: agent (monogram + name) → skill name (`title-panel`) → folder path (`path`) → one plain sentence (`body-lg`) → Now → After pills → the primary Button → "What happens" sentence (`mute`) → Other places (agent tile, name and StatusMark per agent) → links (Open skill, Why isn't it running?). Up to `panel` (392px) wide, pinned while the table scrolls, `shadow-panel`. On phones the same content becomes a bottom sheet. For statuses Skills Manager cannot fix itself (Off in settings), the primary action opens the place to fix it and says so.
